# Cronometro corsa

App web per la corsa: GPS, fasce di ritmo con avvisi a voce, intertempi al chilometro, storico delle uscite e record su 1, 2, 5 e 10 km.
Tutti i dati restano nel browser del telefono (IndexedDB); dalla sezione Altro si scarica e si ricarica un backup.

Apri: https://lucapalmieri88bat-max.github.io/Cronometro-corsa/

File: `index.html` struttura, `app.css` stile, `app.js` logica, `sw.js` funzionamento senza rete, `manifest.json` installazione sulla schermata Home.
